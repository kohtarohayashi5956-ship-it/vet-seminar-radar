# Vet Seminar Radar: 収集精度の改善（2026-11-10）

## 対象
VETS TECH RSSの個別記事を中心に、日程・時刻・申込締切・受講料のエビデンス判定を強化した。既存のv1.0は変更せず、抽出処理と専用テストを追加。

## 改善済み
1. **開催時刻の誤帰属防止**: 記事中の任意の時間帯ではなく、開催日と一致する日時欄の時刻のみを使用する。受付時間、申込期限、別日の予定は採用しない。
2. **開始・終了時刻の両方を抽出**: 21:00～22:30、21：00～22：30、21時～22時半、21時00分～22時30分に対応。複数講座の日付・時刻が混在する場合は推測しない。
3. **申込締切の改行対応**: 「申込締切」の直後に別行で「当日17:30」と書かれた場合、開催日が確定していれば日付に換算する。他項目をまたがない。
4. **無料受講の明記**: 「参加費 無料（見逃し配信10日間）」を無料として認識。無料会員登録と有料参加を取り違えない。
5. **表記・長文対応**: 時刻の全角コロン、記事後半の締切表記を取得対象に追加。
